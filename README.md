## 🚀 Active Projects & Engineering Focus

* **Enterprise Edge Computing:** Designing offline-first architectures, zero-touch provisioning, and secure K3s/K8s deployments at the edge for Fortune 500 enterprises.
* **Off-Grid Comms:** Building and deploying custom, solar-powered Meshtastic nodes using ESP32 hardware and custom-designed 3D printed enclosures.
* **Heavy Homelab Architecture:** Maintaining a robust Proxmox and TrueNAS environment dedicated to self-hosting local LLMs and open-source infrastructure.
